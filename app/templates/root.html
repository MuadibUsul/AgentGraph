The problem问题

Many agents. One source of truth.Agent 很多，事实只有一份。

Without a shared board没有共享黑板时

  • Five agents keep five memories.五个 Agent，五份各自的记忆。
  • Nobody can say who changed what.谁改了什么，没人说得清。
  • A crashed agent holds its task forever.Agent 一崩溃，任务就永远卡住。
  • Every call re-sends the whole world.每次调用都重发全部上下文。

With Veynod有了 Veynod

  • One versioned memory that every agent reads.所有 Agent 读同一份带版本的记忆。
  • Every write is stamped: which agent, with which grant.每次写入都有戳：哪个 Agent、用的什么授权。
  • Leases run out; stuck work returns to READY.租约到期，卡住的任务自动回到 READY。
  • A summary sync carries only what changed.摘要同步只携带变化的部分。
The board黑板

Built for agents. Governed by people.为 Agent 而建，由人来治理。

01

Shared memory with provenance带出处的共享记忆

Documents keep every version. Each write records the agent, its token and its grant.文档保留每一个版本，每次写入都记录 Agent、令牌和授权。

02

Hand-offs with leases带租约的任务接力

Tasks move from agent to agent. If one goes silent, its lease runs out and the task comes back.任务在 Agent 之间接力；谁掉线了，租约到期后任务自动收回。

Every change delivered每次变更都送达
