Tracks the requirements of the 2026-10-21 PRD (58 requirements). "Done" means
implemented with acceptance tests in `tests/`; deviations are listed.

## Phase 1 (in progress)

| ID | Status | Notes |
|---|---|---|
| AG-ST-13 async index | Done | Under `2026-11` writes return `stored=true`, `index_state=pending`; a background worker embeds only the latest queued version (coalescing, `superseded` count), emits `DOC_INDEXED`, retries with exponential backoff and ends as `failed` + `DOC_INDEX_FAILED`. `GET /v1/index/status` / `get_index_status`; queries carry `index_lag`. Baseline clients keep synchronous indexing. |
| AG-CO-03 unified leases | Done | Every task claim is a `leases` record (`lease_<ULID>`) with `fencing_token` (the task's monotonically growing `lease_epoch`), TTL 60–3600 s (900 by default under `2026-11`) and `heartbeat_interval_s` = ttl/3. `heartbeat`, `release_lease`, `list_leases` (REST + MCP); holder task writes count as heartbeats. The reaper emits one `TASK_HEARTBEAT_MISSED` per silent interval and on expiry ends the lease as `expired`, returns the task to READY with `orphaned_from`/`orphan_count`, writes an `auto_generated` continuation at `handoff/<task id>` (heartbeat notes + documents the holder wrote) and emits `LEASE_EXPIRED` (targets: creator, holder); the third orphaning escalates with `repeated_orphan`. Older fencing tokens get 409 `stale_fencing_token`; a holder whose lease ended gets 409 `lease_lost` (2026-11). Revoking a token revokes its leases at once. Optional task `assignee` (403 `not_assignee`). Humans can `POST /v1/human/transfer-responsibilities`. Upgrade: running leases become lease rows; leases without an expiry get 24 h. **Gaps:** slot leases keep their own mechanism; `watermarks` transfer waits for AG-EV-01; retired principals wait for AG-ID-06; document writes do not take a `task_id`/`fencing_token` yet (comes with continuation packs, AG-CO-04). |
| AG-ST-01 census listing | Done | `list_documents` (REST `GET /v1/documents`, MCP) with `order=doc_key_asc|updated_at_asc` (doc_key_asc is the default under `2026-11`): keyset pages of 1–500, every trust state by default, exact `snapshot_count` and `as_of` from the first page carried in an HMAC-signed cursor that also binds the filter (400 `cursor_invalid` when altered or reused with other filters, 410 `cursor_expired` after 24 h), optional `fields` projection, `trust`/`archived` on every item (`trust` is `trust_level`, TRUSTED/UNTRUSTED, as in query hits; the review state stays in `verification_status`). Baseline clients keep the 3.2.1 `(updated_at, id)` listing. **Note:** `include_cold` is accepted but there is no cold tier yet (AG-ST-11); `updated_at_asc` returns a document again if it is updated during the walk (it moves past the cursor), as an incremental sync expects. |
| AG-ST-02 export and import | Done | `POST /v1/exports` (tenant with subtree, workspace or namespace; `since_export_id` for increments; `include_history`, `include`), `GET /v1/exports[/{id}[/download]]`, MCP `export_workspace`/`get_export`/`list_exports`, `POST /v1/imports` (`new_workspace`, `new_tenant`, `increment`) and admin equivalents. Format `agentgraph-export/1` (zip): manifest with per-file sha256 and per-document `{id, alias, version, content_hash}`, documents as JSON-frontmatter Markdown, `objects/versions/doc_edges/grants/events/audit_log.jsonl`, content-addressed `blobs/`, `deleted.jsonl` in increments. Rows are the database's own `to_jsonb`, so new columns travel automatically; every table must be classified (exported/derived/ephemeral) or CI fails, and the round-trip test compares every exported row before and after. Increments diff against the previous export's row-hash index, so base + increments = full. Imports keep ids, aliases, versions, stamps, trust, taint and tombstones; 409 `id_collision`, 422 `checksum_mismatch` (nothing written), 422 `export_format_unsupported`; secrets are never exported (new workspace keys are returned once; tokens must be rotated, users reset passwords) and embeddings are rebuilt by the index worker. Agents get 403; one running export per tenant (409 `export_in_progress`), 4 manual exports per hour. Confirmed tenant deletion takes the final export, downloadable by the owner at `/v1/human/tenant/final-export`. **Gaps:** imports run synchronously in the request; scheduled daily/weekly exports and the 10k-document timing target are not done yet; archives are stored in the database. |
| AG-EV-01 unified event log | Done | `workspace_events` is the outbox (trigger, same transaction). Each event gets `event_id` (`evt_<ULID>`), a dotted `type` (catalogued in `get_api_docs(section="events")`), `targets`, `refs` (pointers, no bodies), `summary`, `shard_key`, and a per-workspace `seq` assigned at commit by a deferred constraint trigger: gap-free and in commit order without serializing writers. `poll_events` / `GET /v1/events` (cursor, types with `*` prefixes, namespaces, `for_me`, `written_by_subtree`, long-poll up to 25 s using short sessions, limit ≤ 500, `oldest_available_seq`, 410 `cursor_expired` with a resync hint). `workspace_sync` / `GET /v1/sync`: every response carries `sync_cursor`; `since=<event cursor>` returns each changed document once at its latest state (`upsert/archive/restore/purge`); poll and sync cursors are interchangeable; exact `namespace_counts` list under `2026-11`; map pagination (`limit` ≤ 2000, `page_cursor`). Events are filtered by namespace read access. Bookkeeping updates (embeddings) no longer emit events. **Gaps:** `mention.*`, `agent.*`, `token.*` and `budget.warning` types wait for their features; the 10k-document sync latency target is not measured. |
| AG-EV-02 prefix subscriptions | Done (logical) | `subscribe` / `POST /v1/subscriptions` with up to 50 `namespace/` or `namespace/doc_key_prefix` prefixes and optional types; `poll_events(subscription_id=…)` returns events in scope plus every event addressed to the caller. `get_orientation` creates and returns the default subscription (the token's readable namespaces). Every event and document carries its `shard_key` (namespace). **Gaps:** tables are not physically partitioned by shard and the index queue is not shard-fair yet (single Postgres, per the PRD's default); task sub-spaces (`tasks/<root>/`) wait for AG-CO-08. |
| AG-ST-06 write semantics | Done | Identical writes are a `noop` (no version bump); connection-pool exhaustion returns 503 `overloaded` with `Retry-After` instead of a 500. |
