implemented with acceptance tests in `tests/`; deviations are listed.

| AG-ST-01 census listing | Done | `list_documents` (REST `GET /v1/documents`, MCP) with `order=doc_key_asc|updated_at_asc` (doc_key_asc is the default under `2026-11`): keyset pages of 1–500, every trust state by default, exact `snapshot_count` and `as_of` from the first page carried in an HMAC-signed cursor that also binds the filter (400 `cursor_invalid` when altered or reused with other filters, 410 `cursor_expired` after 24 h), optional `fields` projection, `trust`/`archived` on every item (`trust` is `trust_level`, TRUSTED/UNTRUSTED, as in query hits; the review state stays in `verification_status`). | AG-ST-02 export and import | Done | `POST /v1/exports` (tenant with subtree, workspace or namespace; `since_export_id` for increments; `include_history`, `include`), `GET /v1/exports[/{id}[/download]]`, MCP `export_workspace`/`get_export`/`list_exports`, `POST /v1/imports` (`new_workspace`, `new_tenant`, `increment`) and admin equivalents. Increments diff against the previous export's row-hash index, so base + increments = full. Imports keep ids, aliases, versions, stamps, trust, taint and tombstones; 409 `id_collision`, 422 `checksum_mismatch` (nothing written), 422 `export_format_unsupported`; secrets are never exported (new workspace keys are returned once; tokens must be rotated, users reset passwords) and embeddings are rebuilt by the index worker. | AG-EV-02 prefix subscriptions | Done (logical) | `subscribe` / `POST /v1/subscriptions` with up to 50 `namespace/` or `namespace/doc_key_prefix` prefixes and optional types; `poll_events(subscription_id=…)` returns events in scope plus every event addressed to the caller. `get_orientation` creates and returns the default subscription (the token's readable namespaces).
